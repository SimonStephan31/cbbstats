Testing for Absence and Equivalence

Course 3 (TAE) · how to support a prediction of “no effect”

A hands-on course that builds on Linear Models in R. Many hypotheses in behavioural research predict the absence of an effect, yet a non-significant result is often misread as evidence for it. The course teaches two ways to test such predictions properly: frequentist equivalence tests and Bayesian alternatives.

Topics

  • Why p > .05 is not evidence for “no effect”: absence of evidence vs. evidence of absence.
  • The smallest effect size of interest (SESOI): how to justify which effects are too small to matter.
  • Equivalence tests (TOST): how to test predictions of “no effect” with classical significance tests, based on a justified SESOI (R package TOSTER).
  • Bayes factors: quantifying the evidence for the null relative to the alternative (R package BayesFactor).
  • Bayesian estimation with a region of practical equivalence (ROPE): deciding on the basis of the posterior distribution (R packages brms and bayestestR).
  • Comparing the approaches: when they agree, when they differ, and the role of priors.

Outcome: each participant plans how to test a “no effect” prediction in their own project, including a sample-size justification.

Key terms: p-value, SESOI (smallest effect size of interest), Equivalence test (TOST), Bayes factor, ROPE (region of practical equivalence), Prior, posterior

Four tests, one dataset

Classical significance tests can do much more than reject an effect of exactly zero. Lakens (2022, ch. 9) distinguishes four kinds of tests. They differ only in which hypothesis is tested, so all four can be applied to the same data: each answers a different question.

The data

Participants solve a puzzle; we measure the solution time in seconds. A control group is compared with a training group (500 participants each). The effect of interest is the time saved by training, Δ = control − training.

  • The smallest effect size of interest (SESOI) is 2 seconds: savings below 2 s are too small to matter in practice.
  • A theory predicts savings between 0.5 and 2.5 s.
set.seed(4)
control  <- rnorm(500, mean = 20,   sd = 5)
training <- rnorm(500, mean = 18.8, sd = 5)

sesoi <- 2                     # smallest effect size of interest (s)
lower <- 0.5; upper <- 2.5     # range predicted by the theory (s)

The observed saving is Δ = 1.25 s, 95% CI [0.65, 1.85], 90% CI [0.75, 1.76].

The four tests at a glance

Code 
lim <- c(-4, 4)
panels <- c("A: two-sided null hypothesis test", "B: interval hypothesis test",
            "C: equivalence test", "D: minimum effect test")
reg <- function(panel, xmin, xmax, hyp) data.frame(panel, xmin, xmax, hyp)
regions <- rbind(
  reg(panels[1], lim[1], lim[2], "H1"),
  reg(panels[2], c(lim[1], upper), c(lower, lim[2]), "H0"), reg(panels[2], lower, upper, "H1"),
  reg(panels[3], c(lim[1], sesoi), c(-sesoi, lim[2]), "H1"), reg(panels[3], -sesoi, sesoi, "H0"),
  reg(panels[4], c(lim[1], sesoi), c(-sesoi, lim[2]), "H1"), reg(panels[4], -sesoi, sesoi, "H0"))
regions$hyp[regions$panel == panels[3]] <- ifelse(regions$hyp[regions$panel == panels[3]] == "H0", "H1", "H0")
regions$panel <- factor(regions$panel, levels = panels)
nil <- data.frame(panel = factor(panels[1], levels = panels), x = 0)
ci  <- data.frame(panel = factor(panels, levels = panels), est = est,
                  lo = c(t95$conf.int[1], rep(t90$conf.int[1], 3)),
                  hi = c(t95$conf.int[2], rep(t90$conf.int[2], 3)))

ggplot() +
  geom_rect(data = regions, aes(xmin = xmin, xmax = xmax, ymin = -.4, ymax = .4, fill = hyp), alpha = .35) +
  geom_segment(data = nil, aes(x = x, xend = x, y = -.4, yend = .4), colour = col_h0, linewidth = 1.6) +
  geom_errorbarh(data = ci, aes(y = 0, xmin = lo, xmax = hi), height = .25, linewidth = 1, colour = col_navy) +
  geom_point(data = ci, aes(est, 0), size = 2.6, colour = col_navy) +
  facet_wrap(~ panel, ncol = 1, strip.position = "left", dir = "v") +

                    labels = c(H0 = "null hypothesis (H0)", H1 = "alternative hypothesis (H1)")) +
  scale_x_continuous(breaks = c(-sesoi, 0, lower, sesoi, upper), labels = c("-2", "0", "0.5", "2", "2.5"),

A: two-sided null hypothesis test

Question: Is there any effect at all? H0: Δ = 0. H1: Δ ≠ 0. The classic t-test; significant if the 95% CI excludes 0.

t.test(control, training, var.equal = TRUE)
#> 
#>  Two Sample t-test
#> 
#> data:  control and training
#> t = 4.0852, df = 998, p-value = 4.757e-05
#> alternative hypothesis: true difference in means is not equal to 0
#> 95 percent confidence interval:
#>  0.6510149 1.8545975
#> sample estimates:
#> mean of x mean of y 
#>  19.85426  18.60146

Result: p < .001. Training saves time, but this test says nothing about whether the saving is large enough to matter.

B: interval hypothesis test

Question: Does the effect fall within the range the theory predicts? H0: Δ ≤ 0.5 or Δ ≥ 2.5. H1: 0.5 < Δ < 2.5. Two one-sided tests, one against each bound; the prediction is supported if both are significant, i.e. the 90% CI lies inside the predicted range.

# H0a: Delta <= 0.5 (test: greater than the lower bound)
p_lo <- t.test(control, training, mu = lower,
               alternative = "greater", var.equal = TRUE)$p.value
# H0b: Delta >= 2.5 (test: less than the upper bound)
p_hi <- t.test(control, training, mu = upper,
               alternative = "less", var.equal = TRUE)$p.value
c(p_lower = p_lo, p_upper = p_hi, p = max(p_lo, p_hi))
#>      p_lower      p_upper            p 
#> 7.133457e-03 2.569832e-05 7.133457e-03

Result: p = .007. The saving lies within the predicted range of 0.5 to 2.5 s.

C: equivalence test (TOST)

Question: Is the effect too small to matter? H0: Δ ≤ −2 or Δ ≥ 2. H1: −2 < Δ < 2. The same two one-sided tests as in B, now against −SESOI and +SESOI; equivalence is shown if the 90% CI lies inside the equivalence bounds.

# H0a: Delta <= -2 (test: greater than the lower equivalence bound)
p_lo <- t.test(control, training, mu = -sesoi,
               alternative = "greater", var.equal = TRUE)$p.value
# H0b: Delta >= 2 (test: less than the upper equivalence bound)
p_hi <- t.test(control, training, mu = sesoi,
               alternative = "less", var.equal = TRUE)$p.value
c(p_lower = p_lo, p_upper = p_hi, p = max(p_lo, p_hi))
#>      p_lower      p_upper            p 
#> 2.791839e-25 7.502522e-03 7.502522e-03

Result: p = .008. The saving is statistically equivalent to zero within ±2 s: it is real (test A), but smaller than anything we consider meaningful.

D: minimum effect test

Question: Is the effect larger than the smallest effect of interest? H0: −2 ≤ Δ ≤ 2. H1: Δ < −2 or Δ > 2. The reverse of the equivalence test; here we test only the direction the theory predicts (Δ > 2).

# H0: Delta <= 2 (test: greater than the SESOI)
t.test(control, training, mu = sesoi,
       alternative = "greater", var.equal = TRUE)$p.value
#> [1] 0.9924975

Result: p = .992. We cannot claim a saving larger than 2 s.

With the TOSTER package

The R package TOSTER runs tests C and D in one call and adds effect sizes and plots:

library(TOSTER)
# C: equivalence test
t_TOST(x = control, y = training, eqb = sesoi, var.equal = TRUE)
# D: minimum effect test
t_TOST(x = control, y = training, eqb = sesoi, var.equal = TRUE, hypothesis = "MET")

Summary

Test Question H0 Result here
A: two-sided null hypothesis test Any effect? Δ = 0 rejected: training saves time
B: interval hypothesis test Within the predicted range? Δ ≤ 0.5 or Δ ≥ 2.5 rejected: prediction supported
C: equivalence test Too small to matter? |Δ| ≥ 2 rejected: equivalent to zero
D: minimum effect test Larger than the SESOI? |Δ| ≤ 2 not rejected

The same data give four different answers because the tests ask four different questions. Which test is appropriate follows from the hypothesis, and should be decided, and preregistered, before the data are seen.

Note: With 500 participants per group, even a saving of about 1 s is detected (A) and shown to be negligible (C). With small samples, typical for animal studies, all four tests are often inconclusive. Planning the sample size for the test you intend to run is part of the course.

Reference: Lakens, D. (2022). Improving your statistical inferences (ch. 9: Equivalence testing and interval hypotheses). https://doi.org/10.5281/zenodo.6409077. Licensed CC BY-NC-SA 4.0.

Simulate first: three answers to the same data

There is no difference between the two groups in these data. The classic t-test is non-significant, but that alone says nothing about whether the effect is absent.

set.seed(13)
n <- 100
a <- rnorm(n); b <- rnorm(n)                 # true difference = 0
sesoi <- 0.4                                 # smallest effect of interest (in SD units)

# 1. Classic t-test: non-significant, but not evidence for "no effect"
t.test(a, b, var.equal = TRUE)$p.value
#> [1] 0.5200304
# 2. Equivalence test (TOST): is the difference within [-SESOI, +SESOI]?
p_lower <- t.test(a, b, mu = -sesoi, alternative = "greater", var.equal = TRUE)$p.value
p_upper <- t.test(a, b, mu =  sesoi, alternative = "less",    var.equal = TRUE)$p.value
max(p_lower, p_upper)                        # < .05 -> effect is statistically equivalent to zero
#> [1] 0.01766867
# 3. Bayes factor for H0 over H1 (BIC approximation; Wagenmakers, 2007)
d  <- data.frame(y = c(a, b), group = rep(c("a", "b"), each = n))
m0 <- lm(y ~ 1, data = d)
m1 <- lm(y ~ group, data = d)
exp((BIC(m1) - BIC(m0)) / 2)                 # BF01 > 1 favours "no difference"
#> [1] 11.46872

In the course, the BIC approximation is replaced by Bayes factors with explicit priors (BayesFactor) and by posterior estimation with a ROPE (brms, bayestestR).
