Inference with Bayesian Causal Models

Course 4 (IBCM) · statistical inference about causal structure and causal strength

A hands-on course that brings together statistical inference and causal inference. Most statistical models answer “how strongly are X and Y related?”. Causal models ask “does X cause Y, and how strongly?”. Bayesian causal models answer both questions in one framework: we specify alternative causal structures as hypotheses, and update our beliefs about them, and about the strength of causal links, in light of data.

Topics

  • Causal Bayes nets: representing causal hypotheses as graphs with parameters
  • Causal structure induction: Bayesian updating over alternative causal structures; the causal support model (Griffiths & Tenenbaum, 2005) and the Structure Induction (SI) model (Meder et al., 2014)
  • Causal strength: Bayesian estimation of the strength of a causal link, with credible intervals
  • Priors: structure priors and parameter priors, and how they shape conclusions from limited data (Stephan & Waldmann, 2026)
  • Bayesian model averaging: combining uncertainty about structure and strength
  • From 2×2 tables to richer structures: multiple causes, common causes and causal chains

Outcome: each participant formulates competing causal hypotheses for their own research question and evaluates them with a Bayesian causal model.

Prerequisites: Linear Models in R. The short workshop Bayesian modelling with brms is a helpful complement.

Key terms: Causal Bayes net, Noisy-OR, Causal support, Structure Induction (SI) model, Causal strength, Bayesian model averaging, Prior, posterior

Worked example: does C cause E?

The simplest causal inference problem: we observe whether a potential cause C is present or absent, and whether an effect E occurs. The data form a 2×2 contingency table. Two causal structures could have generated them:

  • Under S1, E is produced by C (with causal strength wc) and by unobserved background causes A (strength wa). The two causes combine as a noisy-OR: P(e+ | c+) = wc + wa − wcwa, and P(e+ | c−) = wa.
  • Under S0, there is no link: E is produced by A only, so P(e+ | c+) = P(e+ | c−) = wa.
  • A third parameter, the base rate bc of C, is part of both structures. With the same prior in both, it cancels from the comparison, so we leave it out below.

The data

Step 1: how likely are the data under each structure?

Bayesian inference compares structures by their marginal likelihood: how probable the data are under a structure, averaged over all values of its parameters, weighted by the parameter priors. As in the standard SI model, we use flat Beta(1, 1) priors for wc and wa. With two parameters, a fine grid is enough to compute the integral.

si_model <- function(n_ce, n_c, n_nce, n_nc, prior_s1 = .5,
                     wc_prior = c(1, 1), wa_prior = c(1, 1), grid = 401) {
  w <- (seq_len(grid) - .5) / grid            # grid over (0, 1)

  # S1: noisy-OR of C (wc, rows) and A (wa, columns)
  p_c   <- outer(w, w, function(wc, wa) wc + wa - wc * wa)  # P(e+|c+)
  p_nc  <- matrix(w, grid, grid, byrow = TRUE)               # P(e+|c-)
  lik1  <- exp(n_ce * log(p_c)  + (n_c  - n_ce)  * log1p(-p_c) +
               n_nce * log(p_nc) + (n_nc - n_nce) * log1p(-p_nc))
  prior <- outer(dbeta(w, wc_prior[1], wc_prior[2]),
                 dbeta(w, wa_prior[1], wa_prior[2])) / grid^2
  ml1   <- sum(lik1 * prior)                   # marginal likelihood P(D | S1)

  # S0: only A, so P(e+ | c+) = P(e+ | c-) = wa
  lik0 <- w^(n_ce + n_nce) * (1 - w)^(n_c - n_ce + n_nc - n_nce)
  ml0  <- sum(lik0 * dbeta(w, wa_prior[1], wa_prior[2]) / grid)  # P(D | S0)

  post_w <- lik1 * prior / sum(lik1 * prior)   # joint posterior of wc, wa (S1)
  list(ml1 = ml1, ml0 = ml0,
       # causal support (Griffiths & Tenenbaum, 2005)
       support = log(ml1 / ml0),
       # SI model: posterior probability of S1
       p_s1 = prior_s1 * ml1 / (prior_s1 * ml1 + (1 - prior_s1) * ml0),
       # marginal posterior of wc under S1
       w = w, wc_post = rowSums(post_w))
}

r1 <- do.call(si_model, as.list(d1))
r2 <- do.call(si_model, as.list(d2))

Step 2: posterior probability of a causal link

Bayes’ rule combines the marginal likelihoods with the structure prior P(S1):

\[ P(S_1 \mid D) = \frac{P(D \mid S_1)\,P(S_1)}{P(D \mid S_1)\,P(S_1) + P(D \mid S_0)\,P(S_0)} \]

Table Causal support, log P(D|S1)/P(D|S0) P(S1 | D), prior 0.5
1: positive contingency (ΔP = 0.40) 2.81 0.94
2: zero contingency (ΔP = 0) 0.31 0.58
  • Table 1: the data clearly favour a causal link, P(S1 | D) = 0.94.
  • Table 2: although ΔP = 0, the posterior rises above the prior of 0.5. Ceiling data leave the strength of C undetermined: E may be fully produced by A, with C’s influence masked. S1 is consistent with the data over a wider range of parameters than S0, which needs wa ≈ 1. A non-zero belief in a link after zero-contingency data is therefore not necessarily a bias, but can be the result of rational Bayesian updating (Stephan & Waldmann, 2026).

How the posterior depends on the structure prior:

Step 3: what if we are unsure about the prior?

So far the structure prior was a fixed number. Often we are not sure which prior is appropriate. We can express this uncertainty as a distribution over the prior, P(S1) ~ Beta(a, b), and propagate it: each possible prior gives a posterior P(S1 | D). The result is a distribution over the posterior probability of a link, which we can summarise with a 95% interval. We compare an uninformed learner, P(S1) ~ Beta(1, 1), with a sceptical one, P(S1) ~ Beta(2, 8), who expects links to be rare.

post_s1 <- function(prior, r) prior * r$ml1 / (prior * r$ml1 + (1 - prior) * r$ml0)

set.seed(1)
draws <- list(uninformed = rbeta(1e5, 1, 1),   # P(S1) ~ Beta(1, 1)
              sceptical  = rbeta(1e5, 2, 8))   # P(S1) ~ Beta(2, 8), mean 0.2

summ <- function(x) c(mean = mean(x), quantile(x, c(.025, .975)))
round(rbind(`Table 1, uninformed` = summ(post_s1(draws$uninformed, r1)),
            `Table 1, sceptical`  = summ(post_s1(draws$sceptical,  r1)),
            `Table 2, uninformed` = summ(post_s1(draws$uninformed, r2)),
            `Table 2, sceptical`  = summ(post_s1(draws$sceptical,  r2))), 2)

#> Table 1, uninformed 0.87 0.29  1.00
#> Table 1, sceptical  0.74 0.32  0.94

The interval shows how much the conclusion depends on prior assumptions. With Table 1, both learners end up favouring a link, but the sceptic is less sure. With Table 2, the conclusion is driven almost entirely by the prior: the data cannot settle whether C causes E.

Step 4: how strong is the causal link?

Structure induction asks whether C causes E. Causal strength asks how strongly. Within S1, the posterior distribution of wc follows directly from the grid computed in Step 1 (cf. Lu et al., 2008, for Bayesian strength learning). For comparison, the classic point estimate is Cheng’s (1997) causal power, ΔP / (1 − P(e+ | c−)).

wc_summary <- function(r) {
  cdf <- cumsum(r$wc_post)
  c(mean = sum(r$w * r$wc_post),
    lower = r$w[which(cdf >= .025)[1]], upper = r$w[which(cdf >= .975)[1]])
}
round(rbind(`Table 1` = wc_summary(r1), `Table 2` = wc_summary(r2)), 2)
#>         mean lower upper
#> Table 1 0.59  0.19  0.86
#> Table 2 0.55  0.03  0.98
(16/20 - 8/20) / (1 - 8/20)    # causal power for Table 1
#> [1] 0.6666667

ggplot(sp, aes(w, dens, colour = table, fill = table)) +

  • Table 1: the posterior peaks near the causal power, but the 95% credible interval is wide: 40 observations say that C causes E, but not precisely how strongly.
  • Table 2: the posterior is very broad. Ceiling data are compatible with almost any strength of C, because A already produces E every time.

Step 5: combining structure and strength

The strength estimate above assumes that the link exists. Bayesian model averaging keeps the uncertainty about structure: with probability P(S0 | D), wc is exactly 0; with probability P(S1 | D), it follows the posterior under S1.

bma <- function(r) {
  p_zero <- 1 - r$p_s1                                   # probability that wc = 0
  c(`P(wc = 0)` = p_zero, `mean wc` = r$p_s1 * wc_summary(r)[["mean"]])
}
round(rbind(`Table 1` = bma(r1), `Table 2` = bma(r2)), 2)
#>         P(wc = 0) mean wc
#> Table 1      0.06    0.56
#> Table 2      0.42    0.32

This is the step from statistical to causal inference: the question is not only how large an effect is, but which causal structure generated the data, and what follows for the strength of the link if we are uncertain about the structure.
